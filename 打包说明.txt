# 打包说明（单 exe，音频内嵌，防止用户替换）

## 一键打包

1. 确认本机已装 **Python 3.12**，且 `music\A`…`G` 中已放好 wav。
2. 正式测评请确认脚本中：
   ```python
   DEBUG_COPY_FIRST_SCENE_SCORES = 0
   ```
3. 双击运行：
   ```bat
   build_exe.bat
   ```
4. 得到单个文件：
   ```
   dist\盲听音频评分工具.exe
   ```
   拷贝这一个 exe 到目标电脑即可，**不要**再附带 music 文件夹。

## 行为说明

| 内容 | 位置 |
|------|------|
| 测评 wav | 打进 exe 内部，运行时只读，普通用户无法替换 |
| 评分 Excel | 写在 exe 所在目录 |

更换音频源后，必须重新打包，不能靠改外部文件夹热更新。

## 注意

- 目标电脑需要扬声器/耳机。
- 首次启动 onefile 会稍慢（解压到临时目录）。
- 若杀毒软件误报，将 exe 加入白名单。
- 这只能提高篡改门槛，无法做到绝对防破解。

## 手动命令

```bat
pip install pyinstaller pygame openpyxl
pyinstaller --noconfirm --clean --onefile --windowed --name "盲听音频评分工具" --add-data "music;music" --collect-all pygame --collect-all openpyxl blind_listen_score.py
```
